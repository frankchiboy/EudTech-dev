# 專案知識索引

本文件指定 EudTech-dev 的長期作業知識來源。專案內文件是唯一可追蹤、可審查及可隨 Git 版本保存的權威來源；外部對話記憶只可作為搜尋提示，不能取代專案文件。

## 官網版本管理

- 權威文件：[開發中版本管理辦法](開發中版本管理辦法.md)
- 適用範圍：官網每一次程式、內容、設計、設定、表單、SEO、資產及部署更新。
- 核心規則：每次更新建立一個 `codex/<更新名稱>` 分支、使用獨立預覽網址、取得明確正式發布核准後才合併 `main`、每次正式發布建立 `vYYYY.MM.DD-NN` 標籤、以先前正式標籤執行回復。
- 執行要求：任何官網更新開始前，執行人員先閱讀 [開發中版本管理辦法](開發中版本管理辦法.md)；每次更新保存使用者原始指示、驗證結果與發布讀回證據。
