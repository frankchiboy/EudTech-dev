# 使用者原始需求：GPU 配置器預覽版顯示錯誤

日期：2026-08-16（Asia/Taipei）

使用者提供預覽頁面截圖，頁面網址為：

`https://codex-website-next-update--website-eudtech.netlify.app/configurator/`

截圖顯示「Comino Grando GPU 伺服器報價配置器」可以載入產品類型選擇區，但產品資料區顯示「發生錯誤，請稍後再試。」及「重試」按鈕。

本需求要求修正預覽版 GPU 配置器的上游資料中斷情況。修正後，配置器必須在原廠即時配置服務無法連線時使用優達盟已確認的產品配置基準，並清楚告知使用者最終選項、價格與供期仍須由正式報價確認。
