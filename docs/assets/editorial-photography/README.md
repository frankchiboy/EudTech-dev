## 使用規格

- 公開頁面使用 WebP，最長邊不超過 1800 像素。
- Hero 與內容照片使用 `object-fit: cover`；產品圖與原廠介面依內容保留 `contain`。
- 具有內容意義的圖片提供中英文替代文字；與同卡片文字重複的縮圖使用空白替代文字。
- 導覽、表單、狀態、展開、勾選及箭頭等操作圖示保留可辨識的 icon library 元件。
- 品牌標誌、原廠介面、真實產品圖與必要技術辨識元素不由攝影素材取代。
